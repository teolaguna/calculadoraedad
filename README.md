# Calculadora de Edad

Actividad 1 de revisión integral (Python & C++) - LPR 5° 3° A-B.

Programa que calcula la edad exacta de una persona a partir de su fecha de nacimiento
y la fecha actual, validando que la fecha exista en el calendario (años bisiestos y días por mes).

## Estructura

- `proyecto_cpp/` - Código en C++
- `proyecto_python/` - Código en Python
- `docs/` - Documentación del proyecto
- `capturas/` - Capturas de pantalla de ejecución/compilación
